# Проверка выпуска 0.1.2

Выпуск проверен 8 сентября 2026 года на Windows x64. [Релиз и файлы](https://github.com/BLNCname/interview-assistant/releases/tag/v0.1.2).

## Что изменилось

- Все четыре ключа вводятся и удаляются через GUI: LM Studio, OpenRouter, Firecrawl, Context7. Сохранённые в Windows Credential Manager ключи имеют приоритет над резервными значениями окружения.
- Встроенный MCP получает обновлённые ключи после сохранения/пересоздания runtime. Маскирование полей, замена, удаление и раздельное хранение проверены тестами; значения не записываются в YAML.
- Привязка модели LM Studio к конкретному устройству теперь включается явно. Новая установка не требует машины Strix Halo.
- Русский README содержит установку, настройку, первый запуск, четыре скриншота и требования к настольным/мобильным GPU.
- Inno Setup выпускает exe с соседними bin-частями по 1 GiB; все файлы укладываются в лимит GitHub. Установщик не подписан сертификатом издателя.

## Границы проверки

Новых запросов к OpenRouter с настоящим ключом и тестов на RTX 3060 Ti/ноутбучных GPU в этой сборке не проводилось. Рекомендации по памяти являются профилями для проверки, а не измеренным универсальным минимумом. [Требования к оборудованию](../HARDWARE_RU.md).

Ранее измеренные поисковые задержки, расход Firecrawl, STT и скриншоты описаны в [нагрузочном отчёте](stress-and-release-2026-09-08.md). Семантического сжатия контекста отдельным агентом нет; старые факты удаляются при ограничении контекста. Успешная сборка и тесты не гарантируют фактическую правильность каждого ответа модели.
