## Что обязательно проверить при продолжении

1. **Новый важный edge, ещё не исправлен:** FrameValidator считает duplicate
   при dHash Hamming <=4. Кодовый экран `answer = 1` → `answer = 2` может попасть
   в duplicate несмотря на изменённые пиксели. Повторное использование старого
   JPEG тогда возвращает модели устаревший код. Для reuse требуется точное
   равенство кадра (например digest), а изменившийся perceptual duplicate нужно
   сохранять как новый JPEG. Обнаружено read-only агентом search_ddg перед паузой.
2. Агент mcp_client прерван во время дополнительного manual-fix: duplicate.path
   должен работать после расходования pending и иметь приоритет над старым pending.
   Удалённый явно переданный путь не должен возвращать более старый кадр.
   Перед продолжением проверить текущий diff: правка/тесты могли сохраниться частично.
3. Завершить связанные регрессионные тесты, затем один полный финальный прогон.
   Последние полные прогоны **не были зелёными**: окружение мешало Git/PowerShell.
   Доказан и исправлен core.longpaths=true в scan_release_git_history.py и
   inspect_source_archive.py, добавлены два реальных Windows packed-repo regression.
   Focused archive-тесты прошли после исправления runner env. Нужно короткое
   TEMP/TMP в .cache, UV_CACHE_DIR в workspace, UV_OFFLINE=1, native Qt windows,
   убрать PSMODULEPATH из child env без учёта регистра (PS7→PS5 наследование).
   Config roundtrip test изолирован от пользовательского .env; public config
   значения совпадали, различался только private env_path.
4. Packaging добавляет необязательный `-Compression normal|max|ultra64`, прежний
   default ultra64 сохранён; ISS AppCompression macro. 21 focused тест прошёл.
   Для итоговой сборки согласован `-Compression normal`; A/B выигрыш не измерен.
5. Пересобрать окончательный portable, inventory, frozen checks и installer;
   затем installation/diagnostics/uninstall smoke с новой inventory в свежем
   workspace build/<run>/installer-smoke. Скрипт проверяет существующий AppId:
   нельзя перезаписывать регистрацию установленного экземпляра. До паузы такой
   регистрации не было, но перед запуском проверяется снова автоматически.
6. Завершить `docs/validation/stress-and-release-2026-09-08.md`: пока это черновик,
   в нём ещё нет всех поздних screenshot/build результатов.
