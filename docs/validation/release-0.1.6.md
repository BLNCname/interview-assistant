# Проверка релиза 0.1.6

Сборка Windows x64 от 24 ноября 2026 года. Код приложения соответствует коммиту `dd5daa9`. Все 59 модулей приложения, включая точку входа, сверены с байткодом упакованного EXE.

## Исправления и проверки

| Пункты аудита | Что проверено |
|---|---|
| 1–4 | Очистка во время генерации, нумерация ответов между двумя сессиями, три быстро сменившихся вопроса, сохранение без перезапуска активной сессии |
| 5–6 | Постоянный Windows endpoint ID, одинаковые имена устройств, исчезновение выбранного микрофона, восстановление ключей при ошибке записи YAML |
| 7–9 | Пропуск промежуточного декодирования при отставании, счётчик потерянных блоков, сообщение при сбое STT, смена модели во время проверки готовности |
| 10–12 | Локальный режим пользовательской модели, отсутствие токенизатора, HTTPS для удалённого MCP, установка с CUDA и без CUDA |
| 13–14 | Пакетная отрисовка и завершение Markdown-потока, обработка левого и правого Ctrl без повторного вызова действия |

Полный pytest на изолированном рабочем столе Windows — 1 278 успешных тестов. Пять проверок пропущены из-за прав на символические ссылки и специфики POSIX. Ruff и mypy прошли. В локальном тесте Qt рендер 4 000 символов из 500 фрагментов занял 0,029 секунды по медиане трёх прогонов. Время ответа провайдера в этот замер не входит.

Установщик проверен на двух профилях. Базовый прошёл установку, диагностику, повторную установку из кеша и удаление. Полный профиль с CUDA и моделью прошёл установку, проверку опубликованного состава, диагностику EXE и удаление. Содержимое сверено по размерам и SHA-256. При пустом кеше объём обязательных библиотек составляет 285 988 643 байта. CUDA добавляет 1 276 105 266 байт, модель — 1 621 667 428 байт.

Основной переносной ZIP содержит 4 059 файлов, включая закреплённые веса Large v3 Turbo. CUDA ZIP включает остальные 160 файлов. Самостоятельная распакованная копия прошла автономную самопроверку. В GUI этой копии без CUDA обе речевые проверки Large v3 Turbo на CPU завершились успешно при отключённой сети для моделей. После добавления второго архива все 4 219 файлов совпали по размеру и SHA-256 с описью полной сборки.

## Оборудование

На стенде RTX 5070 Ti обнаружены шесть WASAPI loopback-выходов и три микрофона с уникальными ID. На реальном loopback проверены запуск, пауза и возобновление. В собранном EXE через CUDA обе контрольные фразы Large v3 Turbo прошли проверку ключевых слов. Через DirectML на той же карте Tiny распознала английскую фразу и выдала предупреждение о словесных ошибках на русской. Для физических Intel GPU и AMD Radeon проверка остаётся открытой. Во время тестов речевого тракта использовались комплектные записи и локальная конфигурация без внешних запросов к языковым моделям.
