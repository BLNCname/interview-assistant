# Проверка выпуска 0.1.3

Проверено 8 сентября 2026 года на Windows x64, RTX 5070 Ti 16 ГБ, драйвер 610.74. [Релиз](https://github.com/BLNCname/interview-assistant/releases/tag/v0.1.3).

## Результат сборки

Для установки нужен один `Setup.exe`. Код приложения и базовый Python находятся внутри; 35 закреплённых wheel-архивов и 6 файлов STT-модели загружаются с публичных источников PyPI и Hugging Face. Использован Inno Setup 6.7.2, `Compression=none`, без disk spanning. Python, Git, Node.js и CUDA Toolkit на целевой машине не нужны. Драйвер NVIDIA устанавливается отдельно.

| Артефакт | Размер, байт | SHA-256 |
|---|---:|---|
| `Setup.exe` | 38 089 141 | `eb3c6b76b7c12a18bd20899be0991797e9a6cfc05d27ca845299ee65bc24b38f` |
| Установленный `InterviewAssistant.exe` | 14 314 337 | `7d76a7a68d5b55b1abf76049fac08cd0d668dc7e9ea8051a189a7bc92b5582c7` |

Полный portable inventory содержит **4161 файл, 4 017 442 620 байт**. В Setup встроены 103 файла на 34 914 786 байт; 4058 файлов восстанавливаются из проверенных внешних артефактов. Объём загрузок при пустом кеше — **3 087 099 141 байт** без служебного сетевого трафика. Все скачанные архивы и выбранные члены архивов проверены по размеру и SHA-256 против описи полной сборки.

Пять пропусков относятся к трём проверкам symlink, требующим недоступной привилегии Windows, и двум проверкам POSIX. Native Qt и Inno выполнялись на изолированном рабочем столе. Источники программы, установщика и тестов не менялись во время финального полного прогона; входы компилятора отдельно хешировались до и после сборки.

Native-тесты проверяют HTTP 503 с ограниченным повтором, повреждённую загрузку и кеш, остановку настоящей кнопкой Stop download, повторное использование целых файлов, нехватку диска, несовпадение файлов архива и отказ на junction. До завершения подготовки установленное приложение не изменяется. При переходе с 0.1.1 удаляются только 16 конкретных устаревших DLL; при ошибке или отмене подготовки они сохраняются, остальные файлы не удаляются целиком.

## Настоящая установка

Первый кандидат успешно прошёл установку с **пустым пользовательским кешем**: все 41 артефакт действительно загружены штатным HTTPS-механизмом Inno. После установки сверены все файлы, выполнены frozen diagnostics, повторная установка и удаление. Все exit codes — 0; тестовая папка удалена.

| Этап первого сетевого прогона | Время по журналу Inno | Загрузки / попадания в кеш |
|---|---:|---:|
| Установка с пустым кешем | 555,948 с | 41 / 0 |
| Повторная установка | 169,988 с | 0 / 41 |
| Удаление | 2,824 с | — |

Это время одного прогона на данной машине и сети, с параллельными проверками сборки; оно не является гарантией длительности установки. Полный сценарий с проверками занял 770,109 с. Кеш сохраняет только целые проверенные файлы: побайтовой докачки прерванного файла нет.

У первого кандидата SHA-256 `f370e90a4a89a70cb8656fc57106a37e0c95645d9c38fa136a573e65142ff6da`. Затем добавлена точечная очистка старых DLL и установщик пересобран. Manifest внешних артефактов и файлов обоих кандидатов побайтово совпадает: SHA-256 `f5a3b0fac42eb869d704328cf3cfe81ffd99cddc3b8b9c943c232a41ddd77114`.

Окончательный Setup отдельно прошёл установку из заполненного кеша за **146,926 с**, frozen diagnostics, повторное обновление за **151,398 с** и удаление за **2,363 с**. Перед обновлением в тестовую папку добавлены все 16 исторических DLL: после обновления полный inventory снова точно совпал с 4161 файлом новой сборки. Все exit codes — 0, тестовая папка удалена. Обе установки получили по 41 попаданию в кеш и не скачивали артефакты повторно; полный сценарий занял **330,172 с**.

Проверки настоящего установщика запускались в обычном пользовательском контексте на отдельном рабочем столе, который не активировался. Первая попытка из ограниченного контекста агента остановилась до загрузок: этому контексту недоступна запись в AppData. Права и настройки брандмауэра для обхода ограничения не менялись.

## Детектор оборудования и границы проверки

Настоящий Setup определил RTX 5070 Ti, 16 303 MiB VRAM, CC 12.0, драйвер 610.74 и рекомендовал CUDA + Int8/Float16. Установленная сборка сообщила `frozen=true`, `status=ok`, CUDA device count 1 и отсутствие недостающих runtime DLL. Локальные CPU-типы вычислений также доступны.

STT использует faster-whisper 1.2.1 и CTranslate2 4.8.1, а не PyTorch. Для RTX 3060 Ti и RTX 5070 Ti предназначен один закреплённый комплект библиотек. Детектор показывает рекомендацию; существующие настройки не переключаются автоматически. Профили 3060 Ti, 5070 Ti, старого драйвера, малого остатка памяти, 4 ГБ, неизвестного устройства и нескольких GPU проверены подстановкой данных в настоящий Pascal-код установщика.

Физические испытания RTX 3060 Ti, ноутбучных GPU и скорости CPU в этом выпуске не проводились. Визуальное размещение новой аппаратной страницы через Computer Use отдельно не проверено: доступный инструмент подключён к пользовательскому, а не изолированному рабочему столу. Новых платных запросов к OpenRouter/Firecrawl и новых замеров распознавания речи нет; предыдущие измерения остаются в [отчёте записи](recording-replay-2026-09-07.md) и [нагрузочном отчёте](stress-and-release-2026-09-08.md).
