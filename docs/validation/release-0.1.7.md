# Проверка Interview Assistant 0.1.7

Проверка Windows x64 от 24 ноября 2026 года. Код приложения соответствует коммиту `7b8d6b8`. Все 64 модуля, включая точку входа распакованного EXE, сверены с исходниками. Полный pytest на изолированном рабочем столе — 1 290 успешных тестов. Пять тестов пропущены из-за ограничений Windows на символические ссылки и POSIX. Ruff, mypy и проверка lock-файла прошли.

## Подготовка распознавания

На RTX 5070 Ti запуск с пустым кешем обнаружил CUDA, получил Whisper Base и официальные CUDA Runtime/cuBLAS (556 754 500 байт с PyPI). Процесс с включённым PTX JIT выполнил энкодер на реальном звуковом окне. Отдельный процесс проверил английскую и русскую речь с обычными библиотеками декодера. Для драйвера создаётся локальный кеш. Программа разрешает небольшие ошибки в словах для облегчённых моделей согласно критерию речевой диагностики.

Реальный Setup прошёл две проверки. При отложенной подготовке прошли установка, диагностика, повторная установка и удаление. При включённой подготовке мастер дождался компиляции на NVIDIA и проверки речи, затем установка и удаление прошли проверку состава. Отдельная проверка распакованного ZIP подтвердила появление окна подготовки при первом старте, выбор GPU и переход к основным настройкам с валидным профилем.

DirectML прошёл контрольные фразы на той же RTX через DXGI. В этом режиме проверено отсутствие загрузки CUDA-библиотек. Для OpenVINO граф Base с выходом `1 × 1500 × 512` скомпилирован на Intel CPU, повторная компиляция использовала кеш. Маршрутизация на Intel GPU и AMD Radeon проверена тестами с подставными адаптерами. Физических Intel GPU и Radeon на стенде не было.
