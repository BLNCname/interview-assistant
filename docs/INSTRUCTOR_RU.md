# Короткая инструкция для преподавателя

Полная инструкция со скриншотами — в [README](../README.md). Сборка **0.1.4** устанавливается одним сетевым `Setup.exe` и настраивается через интерфейс; обязательного `.env` нет.

1. Откройте [последний релиз](https://github.com/BLNCname/interview-assistant/releases/latest) с GitHub-аккаунта, которому выдан доступ к приватному репозиторию. Скачайте **`Setup.exe`** и сверьте SHA-256 с описанием релиза по README.
2. Запустите `Setup.exe` и дождитесь загрузки библиотек и модели STT — 3,09 ГБ при пустом кеше. Рекомендуется 12 ГБ свободного места с учётом кеша и временных файлов. Устанавливать Git/Python или вводить GitHub-токен в мастер не нужно. При обрыве запустите тот же Setup снова; целые проверенные файлы используются из кеша. [Подробности установки](ONLINE_INSTALLER_RU.md).
3. В **Models** выберите OpenRouter, вставьте ключ, укажите Text model. Для скриншотов заполните Vision model совместимой моделью. Нажмите Save. LM Studio при таком варианте не нужен.
4. В **General → Tools and retrieval** выберите Application MCP. Введите Firecrawl API key и, при наличии, Context7 API key. Нажмите Save. Отдельная установка MCP не нужна.
5. В **Audio** выберите loopback системного выхода, микрофон, NVIDIA GPU (CUDA) и Int8 + Float16. Для RTX 3060 Ti 8 ГБ это рекомендуемый стартовый профиль; работа именно на этой карте ещё требует проверки. Драйвер NVIDIA устанавливается отдельно.
6. Нажмите Save → Run checks, устраните ошибки в Diagnostics и нажмите Start.

Ключи сохраняются в Windows Credential Manager текущего пользователя. Если нужен полностью локальный LLM, выберите LM Studio, включите его API на 127.0.0.1:1234, введите токен и выберите загруженную модель. VRAM этой модели прибавляется к памяти STT.

[Требования к GPU, CPU и памяти, включая ноутбуки](HARDWARE_RU.md). Подтверждённые измерения выполнены на RTX 5070 Ti; 6 ГБ — ориентир для пробного запуска, 8 ГБ — рекомендуемый запас. Без NVIDIA можно выбрать CPU + Int8, но скорость нужно оценить отдельно.

Основные клавиши: Ctrl+Shift+Space — ответ по контексту; Ctrl+Shift+S — скриншот для следующего запроса; Ctrl+Shift+P — пауза; Ctrl+Shift+I — перемещение/редактирование панели; Ctrl+Shift+C — очистка истории.

Для выхода включите взаимодействие через Ctrl+Shift+I и нажмите **Quit** на панели. Если панель скрыта, сначала покажите её через Ctrl+Shift+O.

Для учебной проверки используйте разговор с согласия участников. Модель может ошибаться, а старые реплики удаляются из ограниченного контекста: отдельного семантического сжатия памяти сейчас нет. [Отчёты испытаний](validation/).
