# Начало работы

Для установки и настройки через интерфейс откройте [README](README.md).

- [Скачать актуальный установщик](https://github.com/BLNCname/interview-assistant/releases/latest)
- [Требования к видеокарте и памяти](docs/HARDWARE_RU.md)
- [Запуск и сборка из исходников](docs/BUILD_RU.md)

Скачайте `.exe` и все его `.bin` из одного релиза в одну папку. Ключи LM Studio, OpenRouter, Firecrawl и Context7 вводятся в Settings. Для обычной установки `.env` не требуется.

Старый установщик 0.1.1 в локальном корне проекта и корневой SHA256SUMS.txt относятся к историческому выпуску. Для нового релиза используйте контрольные суммы из его Assets.
